# GRUPO REYGUE INDUSTRIAL — Sitio web corporativo

Sitio estático corporativo en **HTML5 + CSS3 + JavaScript vanilla**, preparado para **Visual Studio Code + Live Server** y **GitHub Pages**.

## Objetivo
Presentar a Grupo REYGUE Industrial como una empresa de ingeniería y soluciones industriales, con énfasis en maquinado convencional, torno, fresado, soldadura, estructuras, mantenimiento, ingeniería, CNC mediante aliados estratégicos, proyectos, renta secundaria y formación.

## Configuración central
Edita `assets/js/config.js` para cambiar WhatsApp, teléfono, email, ciudad, horarios, redes, URL, estado de equipos y precios de renta.

## Proyectos
Edita `assets/js/projects.js`. Los proyectos incluidos inicialmente son **PLANTILLAS DEMO** y están etiquetados para no confundirse con trabajos reales.

## Ejecutar localmente
1. Abre la carpeta completa en Visual Studio Code.
2. Instala Live Server.
3. Abre `index.html`.
4. Presiona **Go Live**.

## GitHub Pages
El proyecto usa rutas relativas y funciona dentro de una ruta tipo:
`https://omarreyes006.github.io/renta-mig/`

Si cambias el repositorio, actualiza `siteUrl` en `assets/js/config.js`, `robots.txt`, `sitemap.xml` y, para SEO social perfecto, las etiquetas Open Graph/canonical de los HTML.
